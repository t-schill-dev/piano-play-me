How to judge it: play each key from C3 up to C5 slowly, one at a time. "Raw note" should match the key right away, and "Steady note" should settle within a moment and not flicker. If it misses soft notes, lower the gate. If it lights keys when nobody is playing, raise the gate. If it jumps between notes, raise "Confidence needed" or "Steady frames".
